# Tech Team Manager

A simple Java console application for managing employees and calculating salaries based on their roles.

This project was developed as part of my Java learning journey with Rocketseat.

## Features

- Register and list employees
- Search employees by name
- Calculate final salaries with role-based bonuses
- Find the employee with the highest final salary
- Count employees by role

## Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList and Map
- Git and GitHub

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/cordeirocesar/tech-team-manager.git
```

### 2. Open the project

Open the project in IntelliJ IDEA.

### 3. Run the application

Run the `Main` class.

## Purpose

A learning project to practice Java fundamentals, object-oriented programming, and code organization.
